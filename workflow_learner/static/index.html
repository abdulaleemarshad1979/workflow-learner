CONNECTED ON YOUR TERMS

Setup & privacy

One local service. Your existing browser. Your choice of what to capture.

1. Connect Brave or Chrome

  1. Open brave://extensions (or chrome://extensions).
  2. Enable Developer mode, choose Load unpacked, and select this project's extension folder.
  3. Done — the companion pairs itself with this app automatically. The header turns green within seconds.
  4. Reload the websites you want to teach, then start a demonstration here.

Pairing only answers the companion's fixed extension ID; websites cannot obtain the key.

2. Teach your real routine

Use your normal Brave tabs, including Gmail and browser based accounting apps. Record one task at a time. Sign in before recording.

Field values become named parameters. Enter the values for each replay. Passwords, payment-card fields, login pages, screenshots, and clipboard contents are excluded.

Broad website access lets the extension work across sites you choose. It sends events only during a recording. Use an origin allowlist to narrow a session.

Desktop apps on Linux

The optional AT-SPI adapter captures accessible focus changes and text-edit locations. It can focus and fill matching accessible controls.

For a desktop button, change its recorded focus step to native_action after review. Apps without accessible controls, canvas based spreadsheets, drag-and-drop, and complex shortcuts need manual steps or a dedicated adapter.

Storage & control

Stop recording anytime. Delete a workflow to remove its demonstrations, revisions, and run history. Input values supplied for a run stay in memory and are not saved in the run log.

Automatic mode runs a reviewed sequence; it is not a general AI that understands every application. Every changed revision requires another review.

The service listens only on 127.0.0.1:8765. It has no cloud model or analytics connection.
